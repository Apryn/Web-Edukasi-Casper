# Signal Casper — Next.js starter

A custom dark editorial fintech landing page for Signal Casper, designed around the supplied Casper identity and cyan accent.

## Requirements
- Node.js 20.9+
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm start
```

## Structure
- `app/page.tsx` — homepage sections and sample article content
- `app/globals.css` — responsive design system and layout
- `app/layout.tsx` — metadata and document layout
- `public/signal-casper.png` — provided brand logo

## Important before publishing
- The XAUUSD chart is an illustrative SVG, not a live price feed.
- The analysis and article sections are design placeholders. Replace them with reviewed content and real publish dates.
- Tools are labeled planned; they are not functional yet.
- Update the contact email, community links, and any CTAs to real destinations.
- No profit claims, testimonials, market prices, or performance statistics are fabricated.
